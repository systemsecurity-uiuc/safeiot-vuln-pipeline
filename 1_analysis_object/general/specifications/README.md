# IoT Protocol Specifications

This directory contains static specification documents for IoT protocols. The current focus is on **Matter**, with planned expansion to ZigBee, Bluetooth, MQTT, and others.

> **Note:** These files are manually maintained due to access restrictions on upstream sources. When new specification versions are released, update the relevant subdirectory by hand and commit the changes.

---

## Matter

The primary focus of SafeIoT's current verification efforts. Matter is a major industry-unifying open-source standard backed by Amazon, Apple, Google, and hundreds of other vendors.

### Update Instructions

1. Download the latest specification from the [CSA Matter Resources page](https://csa-iot.org/developer-resource/specifications-download-request/).
2. Place the file(s) under `specifications/matter/`.
3. Update the Contents list above.
4. Commit with a message referencing the spec version (e.g., `add Matter Core Spec v1.4`).
