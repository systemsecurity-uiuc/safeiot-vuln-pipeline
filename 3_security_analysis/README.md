# Stage 3 — Security Analysis

The verification itself: the checks, detection logic, formal models, agents, or
experiments that decide whether the analysis object has the weakness in question.

Each tool gets a subdirectory named after the tool.

```
3_security_analysis/
└── <tool-name>/
```

Every tool has this stage. Keep the analysis logic here; collecting the object,
preparing it, and reporting the results belong to the other stages.
