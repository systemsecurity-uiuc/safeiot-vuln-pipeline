# CHIP SDK Setup

This directory provides instructions and helper scripts for setting up the [CHIP SDK](https://github.com/project-chip/connectedhomeip) (Connected Home over IP), the open-source reference implementation of the Matter standard.

## Overview

The CHIP SDK (also known as `connectedhomeip`) is a large external repository and is **not vendored here**. Instead, this directory documents how to obtain and configure it for use with the SafeIoT pipeline tools.
